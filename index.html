From factors to a score

Combined index = share × traditional + (1 − share) × alternative. The traditional share is 45% for new customers, 60% for weak and 75% for strong relationships, following the FICO table where alternative data adds the most for new customers.

Score = 300 + 600 × index.
Default probability = 1 / (1 + e^(−1.86 + 7.19 × index)), tuned so index 0.5 gives 15% and 0.8 gives 2%.
Expected loss = PD × 45% loss given default × loan amount.
Rate = 11% + 40 × PD, capped at 36%.

Thin file rule: with no credit history, the traditional model has nothing to read, so it gets a floor index of 0.30. A borrower with strong alternative data but a thin file is flagged as an invisible prime.

The curve is illustrative, not fitted to real defaults. To use it for real lending, calibrate it on repayment data and test it for bias across groups.
